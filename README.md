# Apurva Bridal (Patna) — Luxury Bridal Atelier & Interactive Runway

A premier luxury Indian bridal couture web application inspired by high-end MotionSites/fashion runway experiences. Built with Vite, React 19, Tailwind CSS v4, and Motion/React.

## ✨ Experience Features

- **3D Cylindrical Runway ("Try the Look")**:
  - Continuous 3D cylindrical ring with critically damped spring dynamics.
  - Two-finger trackpad horizontal scrubbing on Mac, inertia momentum touch on mobile, and drag navigation.
  - Front-model zoom with numbered hotspot pins and dynamic headroom clearance.
  - Atmospheric breathing floor lighting, cinematic specular light sweeps on transitions, and catwalk mirror floor reflections.
- **Suspended 3D Clothing Rail ("The Rack")**:
  - Edge-on hanger physics with 3D perspective rotation, velvet zardozi craft notes, and sizing selector.
- **Endless Tactile Swatch Deck ("Pick a Silk")**:
  - Infinite circular modulo loop carousel with curved arc fan kinematics and 3D cursor-tracking perspective tilt.
- **Curated Bridal Archives & Editorial Lookbook**:
  - Interactive fabric archive arches, royal ensemble bundle savings, and responsive quick-commerce bag dialog.

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite 6
- **Styling**: Tailwind CSS v4 + PostCSS
- **Animation & Physics**: Motion (`motion/react`)
- **Icons**: Lucide React

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Production build & TypeScript check
npm run build
```
